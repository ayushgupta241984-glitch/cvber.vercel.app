# CVBER Brain — Knowledge Vault

Persistent memory for the CVBER JARVIS agent.

## Structure

- `knowledge/` — Long-term facts, decisions, patterns
- `trajectory/` — Action logs (what the agent did and why)
- `patterns/` — Detected recurring patterns in artwork theft
- `scan-history/` — Record of every file scan performed

## Obsidian Compatibility

This vault is compatible with Obsidian. Open it in Obsidian to browse, search, and link notes.
